A detection and tracking pipeline for deer (*doe*) using computer vision.

## Overview

This project implements an end-to-end pipeline for detecting and tracking deer in video footage. The pipeline combines object detection with multi-object tracking to follow individual animals across frames.

## Getting Started

Clone the repository and add your video footage to get started:

```bash
git clone https://github.com/jverwaer/doeTracking.git
cd doeTracking
```
